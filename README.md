# Росток — игровое банковское приложение

## 1. Обзор проекта

### Что такое Росток

**Росток** — игровой клиент (`artifacts/bank-game`) и сервер (`artifacts/api-server`) поверх **демо-накопительного счёта**. Игрок ухаживает за виртуальным деревом: копится энергия, проходятся мини-игры, завершается цикл **ухода**, начисляются опыт, рост дерева и денежный доход.

Для банка цель — игровой слой над реальным вкладом. В репозитории сейчас **демо**: вход по email и паролю, стартовый капитал **100 000 ₽**.

### Игровая идея

Ежедневный ритуал вместо «забыл про вклад». Открыл приложение → забрал энергию из корней → прошёл три мини-игры → нажал **«Уход»** → увидел рост дерева и доход.

### Почему дерево связано с экономикой, но не равно деньгам

| Слой | Что это | От чего зависит |
|------|---------|-----------------|
| **Деньги** | рубли на счёте (сейф / сундук), доход за уход | капитал в сундуке, финансовое время, навык игры, свежесть |
| **Игра** | энергия, корни, мини-игры, Метёлка | реальное время, ёмкость, действия игрока |
| **Рост дерева** | миллиметры и стадии | длительности активностей, навык, коэффициенты ухода — **не сумма рублей** |

Капитал **ускоряет** накопление энергии и участвует в **денежном** доходе. Высота дерева считается **другой** формулой: рубли в рост в миллиметрах **не входят**. Дерево показывает прогресс привычки ухаживать, а не копирует баланс один в один.

## 2. Как устроена экономика

Одна цепочка. Каждый шаг опирается на предыдущий.

```
Капитал
  ↓
Финансовое время
  ↓
Генерация энергии
  ↓
Накопление в корнях
  ↓
Активности ухода
  ↓
Рост дерева (+ доход в ₽ и опыт при «Уход»)
```

### Роль каждого звена

| Звено | Простыми словами |
|-------|------------------|
| **Капитал** | Деньги демо-счёта. В **сейфе** — вне игры (колба медленная). В **сундуке дерева** — в игре: ускоряет энергию и базу денежного дохода. |
| **Финансовое время** | Сколько игровых секунд энергии набежало за реальное время при данном капитале (через формулу `T(K)`). |
| **Генерация энергии** | Энергия копится сама, пока идёт время. Больше капитала в сундуке — быстрее (с затуханием). |
| **Накопление в корнях** | Три корня (Полив / Свет / Удобрение) копят энергию; игрок **собирает** её в запасы кнопок. |
| **Активности ухода** | Три мини-игры на запасах; все три → кнопка **«Уход»**; сервер фиксирует навык, опыт, рубли, миллиметры. |
| **Рост дерева** | Начисление миллиметров и смена стадии. Деньги и опыт считаются отдельно, но в том же завершении ухода. |

Если обычная ёмкость заполнена, часть энергии уходит в **избыток**; тогда перед обычным уходом нужна **Метёлка**.

### Скорость энергии

```
T(K) = 3600 / (1 + 4 · (K / 100000)^0.15)
```

`T(K)` — сколько **реальных секунд** нужно на **1 игровую секунду** энергии. `K` — капитал в сундуке.

| Капитал | Пример |
|---------|--------|
| 0 ₽ | около 60 минут |
| 100 000 ₽ | около 12 минут |
| больше | быстрее (с затуханием) |

### Деньги, игра и рост — три разных результата

```
  Капитал в сундуке ──► Финансовое время T(K) ──► Энергия → Корни → Активности
           │                                              │
           └──────────────► Доход в ₽ ◄───────────────────┘
                            (навык, свежесть)

  Активности (длительности + навык) ──► Рост в мм
                                        (без рублей в формуле)
```

## 3. Словарь

| Термин | Простыми словами |
|--------|------------------|
| **Капитал** | Деньги на демо-счёте. Сейф — вне игры; сундук — в игре. Старт: 100 000 ₽. |
| **Финансовое время** | Игровое время из реального через `T(K)`: сколько энергии дало время при этом капитале. Участвует и в расчёте рублей за уход. |
| **Энергия** | Игровой ресурс в секундах. Копится сам. Нужен для корней и мини-игр. |
| **Корни** | Три хранилища под деревом (Полив / Свет / Удобрение). Наполнились — перенос в запасы кнопок. |
| **Уход** | Три мини-игры + кнопка **«Уход»**. На сервере цикл завершается и начисляются опыт, рубли, миллиметры. |
| **Метёлка** | Отдельная активность (уборка паутины), когда накопился избыток. Пока не пройдена, обычный уход может быть закрыт. |
| **Избыток** | Энергия сверх обычной ёмкости корней и запасов. Ведётся отдельно; ведёт к Метёлке. |
| **Рост (мм)** | Миллиметры дерева. Пороги стадий: 0 / 50 / 200 / 500 / 850 мм. Это **не** «столько рублей = столько миллиметров». |

| Ещё | Значение |
|-----|----------|
| **Навык** | Качество мини-игры от 0 до 1 (в интерфейсе часто 0–100%). Влияет на опыт, бонус рублей и миллиметры. |
| **Свежесть** | От 0,50 до 1,00; влияет на бонусный процент дохода. |
| **Пресет** | Длительность активности в игровых секундах (обычно 5–25). |
| **Запас** | Энергия на кнопке после сбора корня. |

## 4. Как устроены слои внутри

Это не «старое и новое», а **как устроен продукт сейчас**: деньги, энергия и рост дерева считаются по разным правилам.

| Слой | За что отвечает | Куда смотреть в коде |
|------|-----------------|----------------------|
| Скорость энергии | формула `T(K)`, генерация | `api-server/src/services/` — `secondsPerGameSecondForCapital` |
| Хранение энергии | корни, запасы | `api-server/src/services/` — roots, capacity, excess-gate |
| Капитал | сейф и сундук | `api-server/src/services/` — capital-vault |
| Уход | игры, завершение, рубли, опыт | `api-server/src/services/` — care, care-income, care-xp; `routes/` |
| Избыток и Метёлка | избыток, метёлка | `api-server/src/services/` — excess-gate, metelka |
| Рост дерева | миллиметры | `api-server/src/services/` — tree-growth |

## 5. Как устроена техника

### Сервер — главный источник правды

- Клиент **не** хранит истину по балансу, энергии, миллиметрам и наградам.
- Всё читается и меняется через `/api/game/...` (сессия в cookie).
- В разработке Vite направляет `/api` на `http://localhost:8080`.

### База данных

- Игровое состояние в **PostgreSQL**.
- Учётные записи, балансы (сейф / сундук), туториал, опыт, `tree_growth_mm`, корни, циклы ухода, Метёлка, журнал дохода.

### Сервер считает награды

При «Уход» сервер считает и записывает:

- денежный доход;
- опыт;
- миллиметры роста;
- статусы ухода и Метёлки.

Клиент не должен сам «придумывать» финальные рубли и миллиметры.

### Клиент — картинка и нажатия

- Сцена, анимации (опыт → рост → монеты и яблоки), подсказки туториала, мини-игры.
- Отправляет действия на сервер и показывает ответ.

```
Действие игрока → API → PostgreSQL и расчёты
                              ↓
                         состояние
                              ↓
                    анимации и интерфейс
```

## 6. Путь игрока

```
регистрация
  → онбординг (демо-счёт 100 000 ₽)
  → обучение
  → капитал          (посадить росток → перенести капитал в сундук)
  → энергия          (колба / ожидание / ускорение в обучении)
  → корни            (собрать три корня)
  → активности       (Полив, Свет, Удобрение — в любом порядке)
  → уход             (кнопка «Уход»)
  → награда          (опыт, рубли, сбор монет и яблок)
  → рост дерева      (+N мм, смена стадии)
```

Дальше тот же цикл в основной игре. Если ёмкость заполнена — сначала **избыток → Метёлка**, потом обычный уход.

### Обучение (кратко)

| Шаг | Что видит игрок |
|-----|-----------------|
| приветствие | план «Ухаживайте за деревом» |
| посадка | «Посадите росток» |
| капитал | энергия без капитала → перенос в сундук |
| энергия | ускорение / ожидание колбы |
| корни | «Соберите энергию из корней» |
| активности | «Пройдите активность» |
| «Уход» | «Нажмите на кнопку «Уход»» |
| награда | «Соберите награду» |
| финал | «Начать играть» |

## 8. Механики подробнее

### Сейф и сундук

- **Сейф** — капитал вне игры, колба медленная.
- **Сундук** — капитал в игре.
- В обучении кошелёк перетаскивают из сейфа в сундук.

### Корни и запасы

- Три корня, ячейки по 5 секунд.
- Сбор в запасы кнопок; без сбора уход ограничен.
- Ёмкость: пресет (часто 5–25 с) плюс бонус серии визитов; корень + запас не больше ёмкости.

### Три мини-игры

| Активность | Файл | Суть |
|------------|------|------|
| Полив | `FallingGameWater` | ловить капли |
| Свет | `ClickGameSun` | нажимать на лучи |
| Удобрение | `FertilizerMatchGame` | собирать гранулы в ряд |

После третьей игры кнопки сходятся в **«Уход»**.

### Награды за «Уход»

На экране по очереди: **опыт → рост в мм → монеты и яблоки → рубли в сундук**.

**Денежный доход (считает сервер):**

- база: `capital × 0.12 × elapsed / секунд_в_году`
- бонус: от 1,5% до 3% годовых — от навыка цикла и свежести

Ставки **тестовые**.

**Рост в миллиметрах (считает сервер):**

```
мм = T × навык × коэффициент_ухода × долгий_уход   (вниз до целого)
```

- `T` — сумма трёх пресетов (15…75)
- навык — среднее по трём играм; при нуле всё равно **1 мм** за завершённый цикл
- коэффициент ухода — среднее `C(t) = 1.25 − 0.01t` по пресетам
- долгий уход растёт с числом успешных уходов за жизнь аккаунта (до примерно 1,5)

**Стадии:** Росток (0) → Саженец (50) → Деревце (200) → Молодое дерево (500) → Могучее дерево (850+ мм).

### Метёлка и избыток

1. Ёмкость полная → энергия идёт в **избыток**.  
2. Появляется **Метёлка**.  
3. После прохождения — награда, снова обычный уход.

## 9. Зачем это клиентам и банкам

**Клиентам:** ритуал вместо забытого вклада; видно дерево, миллиметры, уровень и капитал.

**Партнёрство:** в будущем — доступ к реальному счёту с разрешения клиента. Сейчас в коде — демо-счёт.
